# Changeloom — PRODUCT.md

**Register:** product (app UI / developer tool — design serves the task).

**What:** a dark, no-signup web portal that turns any GitHub repo URL into an
"what actually changed + should I upgrade" workspace — categorized changelog,
release insights, contributor intelligence, and export.

**Who:** open-source maintainers cutting releases, and developers evaluating or
upgrading a dependency. Fluent in Linear / Vercel / GitHub — they expect earned
familiarity and density, not novelty for its own sake.

**Scene:** a developer, late, deciding whether to upgrade a dependency or
drafting release notes — deep-focus, dark editor light, wants answers fast and
scannable, then gone.

**Design system:** the "Loom" — deep near-black blue surfaces, a single luminous
cobalt thread as the only saturated color at rest, semantic category colors used
only to encode data, Geist sans + Geist Mono (mono for every datum). Full spec
in [DESIGN.md](DESIGN.md).

**Bar:** the tool disappears into the task. Consistent component vocabulary,
hairline-bordered panes (no ghost cards), tabular-nums everywhere, motion that
conveys state, 4.5:1 contrast, keyboard-first.
